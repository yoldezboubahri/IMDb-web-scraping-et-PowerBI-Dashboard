# Data

- `IMDB_DATA.csv`: dataset supplied with the project (250 movie records).
- `IMDB_DATA_scraped.csv`: generated by `src/scrape_imdb.py` when the scraper runs.

The scraper reconstructs the visible Selenium + BeautifulSoup workflow. The supplied CSV also contains `Pays` and `Langue` fields; those enrichment steps are not visible in the provided code screenshots and are therefore not fabricated by the reconstructed script.

Check IMDb's terms and usage policies before collecting or redistributing data.
